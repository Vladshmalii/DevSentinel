# DevSentinel MVP Architecture

DevSentinel — локальный десктоп-ассистент для разработчика. Ниже описана целевая архитектура первой версии и черновая реализация модулей на Python 3.10.

## Компоненты

### Vision (`src/devsentinel/vision`)
* `VisionAnalyzer` управляет `cv2.VideoCapture`, периодически извлекает кадры и прогоняет их через модель.
* Пока встроен `dummy_model`, который использует яркость кадра как прокси внимания. Позже его заменят на PyTorch-инференс с эмо-моделью / Mediapipe landmarks.
* Возвращает `VisionState` с признаками присутствия, внимания, усталости, стресса и дискретным настроением.

### Audio (`src/devsentinel/audio`)
* `AudioListener` опирается на абстрактный `SpeechToText` backend (например, Whisper или Vosk).
* В репозитории есть `DummySTT` для офлайн-тестов и `CommandParser`, который распознаёт команды «фокус N минут», «перерыв N минут», «запиши заметку: …».
* `audio_state()` выдаёт грубые эмоции по голосу на основе уверенности STT.

### NLU
* MVP реализован через `CommandParser`. Позже его можно заменить на полноценный NLU-модуль без изменения интерфейсов.

### State Engine (`src/devsentinel/state`)
* `StateEngine` агрегирует `VisionState` и `AudioState`, поддерживает сглаженные `focus_level`, `fatigue_level`, `stress_level` и управляет таймерами.
* Команды переводятся в события: запуск фокус-сессии, перерыва, сохранение заметок. Все изменения отражаются в `EngineState`.

### UI (`src/devsentinel/ui`)
* `OverlayWidget` — PySide6-оверлей (always-on-top, прозрачный фон). Показывает текущее состояние движка и таймеры.
* Позже сюда добавят персонажа, xp/реплики, затемняющие экраны.

### Speech/TTS (`src/devsentinel/speech`)
* `VoiceAssistant` оборачивает локальный `pyttsx3`, чтобы голосом подтверждать команды и напоминания.

### Storage (`src/devsentinel/storage`)
* Локальная SQLite через `Storage`. Хранит заметки и историю фокус/брейк-сессий.
* Схема разворачивается автоматически.

### App Glue (`src/devsentinel/app.py`)
* `DevSentinelApp` связывает все модули, обновляет состояние и демонстрирует, как обрабатывать распознанные сегменты речи.
* `main()` запускает vision-loop (без UI, чтобы не блокировать терминал) и печатает состояние раз в секунду.

## Следующие шаги

2. Добавить асинхронный event-loop, чтобы параллельно обрабатывать vision/audio, overlay и TTS.
3. Расширить NLU (распознавание ругани, контекст, предложения о паузе).
4. Реализовать fatigue/stress накопление, уведомления и затемняющий break-экран.
5. Дополнить UI персонажем, xp/репликами и интерактивными подсказками.
